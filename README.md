# RepEng — AI-репетитор английского

Локальное веб-приложение: нейросеть ведёт с тобой разговор на английском, исправляет ошибки, оценивает произношение и помнит твой прогресс между занятиями.

## Возможности

- **Разговор голосом или текстом** на свободную тему или в ролевой ситуации. Исправления показываются под репликой, не перебивая беседу.
- **Долгосрочная память** в SQLite: уровень CEFR, цели и интересы, повторяющиеся ошибки, словарь, слабые звуки, итоги прошлых занятий. Перед каждым занятием репетитор получает сводку.
- **Оценка произношения и акцента** на уровне звуков: что прозвучало вместо нужного (например /θ/ → /s/).
  - Azure Pronunciation Assessment — точность, беглость, интонация;
  - локальная фонемная модель (wav2vec2 + g2p), офлайн;
  - аудио-LLM (Gemini и др.) — советы «на слух».
- **Вводный тест** для определения уровня.
- **Тренировка произношения:** фразы подбираются под твои слабые звуки.
- **Повторение:** карточки слов (SM-2) и упражнения по твоим ошибкам.
- **Прогресс:** график навыков, статистика по звукам, история занятий.

## Подключение моделей

| Что | Варианты |
|---|---|
| Репетитор (LLM) | любой OpenAI-совместимый API (OmniRoute, OpenRouter, OpenAI, Groq, Ollama, LM Studio, …) или Anthropic напрямую |
| Распознавание речи | браузер (Chrome/Edge), Whisper API, аудио-LLM, Azure, локальный faster-whisper |
| Оценка произношения | Azure, локальная модель, аудио-LLM |
| Озвучка | браузер, Azure Neural TTS, OpenAI-совместимый `/audio/speech` |

Всё настраивается во вкладке «Настройки».

## Запуск (Windows)

Нужен Python 3.10+.

```bat
run.bat
```

Скрипт создаст `.venv`, установит зависимости и откроет http://localhost:8000.

Вручную:

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m uvicorn backend.app.main:app --port 8000
```

Офлайн-оценка произношения и локальное распознавание (~2 ГБ, модель скачается при первом запуске):

```bash
.venv/Scripts/pip install -r requirements-local.txt
```

## Где хранятся данные

- `data/settings.json` — настройки и **API-ключи** (открытым текстом);
- `data/repeng.db` — память и прогресс.

Папка `data/` исключена из git.
